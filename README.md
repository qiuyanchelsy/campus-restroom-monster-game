# 校園廁所怪獸冒險

本遊戲適用 iPad Safari、電腦瀏覽器，無須登入或伺服器資料庫。

## 啟動
將本資料夾內 `index.html` 與 `assets` 資料夾放在同一位置。用瀏覽器開啟 `index.html`，或將整個資料夾上傳 GitHub Pages。

## 功能
- 首頁繪圖模型製作的遊戲封面與四個探索區
- 四隻獨立 PNG 怪獸素材、淨化提示和結局守護員稱號
- 質數、因數、公因數、公倍數四關隨機出題
- 四位數密碼依本局題目計算；新一局重抽
- 情境題、DFC 改善提案、結局證書
- iPad 觸控設計，儲存進度於裝置
- 起始時可選填學生姓名，結尾證書會顯示姓名、四位數密碼與調整答案次數
- 結局可直接列印為學生的「校園廁所守護者證書」

## 課堂操作（35 分鐘）
1. 3 分鐘：投影封面，請學生找出四個廁所常見問題。
2. 18 分鐘：兩人一組輪流操作；每次點選前先口頭說出判斷質數、因數、公因數或公倍數的策略。
3. 8 分鐘：完成各關 DFC 情境題，說明為什麼正確選項能兼顧安全、責任與環境。
4. 6 分鐘：完成第五關改善提案，挑選 2～3 份提案作為班級廁所公約候選。

注意：為保持關卡可控，地圖依序解鎖；守護員使用原角色加光效及稱號，不是另外繪製的第二套角色。封面圖的遊戲按鈕為示意位置，網頁上的實際點擊按鈕會覆蓋相應區域。
